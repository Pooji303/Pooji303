## 🛒 Order & Transaction Analysis (SQL Project)

**Tools Used:** MySQL  
**Domain:** Retail / E-Commerce  
**Objective:** Analyze customer orders, transactions, and purchasing patterns to uncover business insights.

### 🔧 Key Processes:
- ✅ Created and used an SQL database `orders`.
- 🧬 Merged `orders` and `details` tables using `LEFT JOIN` to form a unified dataset `merged_orders`.
- 🧹 Cleaned data:
  - Converted `Order_Date` from text to proper `DATE` format using `STR_TO_DATE`.
  - Checked for and handled null values and duplicates.
- 📊 Performed detailed data exploration and aggregation.

### 📈 Data Exploration & Insights:
- 🧾 **Popular Payment Modes:** Identified the most-used payment methods and associated spending.
- 💰 **Category Performance:** Analyzed sales and profit by product category and sub-category.
- 🏆 **Top Customers:** Listed customers by total spend and number of orders.
- 🕒 **Order Trends Over Time:** Tracked order volumes by year and month to identify peak periods.
- 📍 **State-wise Performance:** Ranked states by total orders and profits.
- 🔁 **Customer Retention:** Identified repeat customers with multiple orders.
- 📦 **Top-Selling Sub-Categories:** Measured performance by product quantity sold.

### 💡 Business Value:
This analysis helps stakeholders:
- Understand key revenue drivers.
- Plan inventory and marketing around top categories and regions.
- Improve customer engagement by targeting loyal customers.
- Optimize payment method offerings.
